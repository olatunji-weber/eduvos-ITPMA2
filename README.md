# eduvos-ITPMA2
Project Management Assignment ITPMA2-33

This assessment traces a failed ERP-style project caused by weak stakeholder ownership and missing governance, then outlines a recovery plan combining project review, requirements management, Agile/Scrum sprints, JIRA, Kanban with WIP limits, and better resource management; it builds a Level 3 WBS and an AON network diagram for an 8-task ERP implementation, calculates a critical path of T1→T2→T3→T4→T5→T6→T7→T8 spanning 35 days with zero float on every task, confirms this with a ProjectLibre Gantt chart, and closes by noting two Gantt chart limitations (hidden task dependencies and unrealistic resource-availability assumptions) along with fixes for each.
